# 报销单生成（invoice2Excel）

基于 **Tauri 2 + Rust** 的 Windows 桌面小工具：填表单 → 另存为对话框 → 生成 .xlsx。

## 功能

- **基本信息**：姓名、日期（日期选择框，默认今天，旁边“今天”按钮一键回到今天）、部门（预设下拉 + 可自由输入）、项目名称（可留空）。
  - 姓名、日期、部门为**必填**，点“生成”时校验。
- **报销明细**：带序号的可自增表格（默认 2 行；末行有内容自动补行，也可点“＋ 添加一行”，每行可删除）。
  - 摘要：预设 市内交通费 / 餐费 / 软件费，可选择也可自由输入；
  - 金额（元）：仅数字，整数最多 7 位、最多两位小数，上限 9,999,999.99；
  - 附单据数：非负整数；
  - **行完整性校验**：一行中只要有一格有值，其余格子必填（整行留空允许），违规行会标红并提示行号。
- **实时预览**：汇总金额框左上角显示“汇总金额”标签，右下角分两行显示带千分位的小写金额（蓝色大号）与人民币大写。
- **校验提示**：必填缺失或明细不完整时弹出“请检查”弹窗，点“确 定”关闭后修改。
- **重置**：一键恢复表单初始状态（日期回到今天、明细回到 2 个空行）。
- **自动删除空行**：默认勾选。空行 = 摘要、金额、附单据数均为空；取消勾选则原样保留空行（便于打印后手工补填）。
- **生成**：弹出“另存为”对话框，默认文件名 `姓名_部门_YYYY-MM-DD.xlsx`，默认目录记忆上一次保存位置；生成成功后点提示条上的“打开文件夹”，在资源管理器中定位生成的文件。

## 生成的 Excel 版式（严格对照模板文件）

- A4 **横向**，页边距 0.7/0.7/0.75/0.75（英寸），与模板一致。
- 标题“费 用 报 销 单”：宋体 21 加粗，B2:O2 合并，行高 30；其余行高统一 33。
- 日期单元格为真实日期值，显示格式 `2026年7月27日`（黑体 12）。
- 部门 / 项目名称行与表头：宋体 12；明细金额：Arial 12。
- 列宽逐列复刻模板（B..O，与模板存储值偏差 < 0.5px）。
- 每条明细一行：摘要=B:F、金额=G:K、附单据数=L:O（细边框）。
- 合计行：`人民币(大写) 肆仟零陆元柒角肆分` + 小写金额；无金额时留白。
- 审批行：领导批示(B:D) / 财务经理(E:F) / 分管领导(G:K) / 部门经理(L:O)。
- 签字行：黑体 11，整行合并 `财务审核　出纳　报销人　领款人`，无边框。
- 注：模板文件空行区域原有一条斜线（绘图残留），生成文件未复刻该杂项。

## 构建与运行

根目录 `package.json` 提供了全部常用命令（Node 仅作脚本编排，无需 `npm install`）：

| 命令            | 作用                                                                                        |
| --------------- | ------------------------------------------------------------------------------------------- |
| `npm run dev`   | 调试运行：debug 编译并启动应用（前端为静态资源、编译期嵌入，改动 `ui/` 后重新运行即可生效） |
| `npm run build` | 打包：**自动先清空 `dist/`** → `cargo build --release` → 产物复制到根目录 `dist/`           |
| `npm run zip`   | 把 `dist/invoice2excel.exe`、`使用说明.txt` 与 `README.md` 打成 `dist/报销单生成.zip`       |
| `npm test`      | `cargo test`（人民币大写、日期/金额解析等单测）                                             |
| `npm run icon`  | 重新生成 `src-tauri/icons/icon.ico`（蓝色圆角方块 + 白色 ¥）                                |
| `npm run clean` | 仅清空 `dist/`                                                                              |

打包流程（`npm run build` 通过 npm 生命周期钩子自动串联）：

1. `prebuild`：`scripts/clean-dist.js` 清空根目录 `dist/`；
2. `build`：`cargo build --release`，产物为独立单文件 exe（Windows 10/11 自带 WebView2 运行时，双击即可运行）；
3. `postbuild`：`scripts/pack-dist.js` 把 `invoice2excel.exe` 和 `assets/使用说明.txt` 复制到 `dist/`。

> 说明：exe 图标由 `src-tauri/icons/icon.ico` 在编译期写入；若资源管理器显示旧图标，是 Windows 图标缓存所致，重命名 exe 或重启资源管理器即可刷新。
>
> 注意：打包前请先关闭正在运行的旧版应用——Windows 会锁定运行中的 exe，cargo 无法替换它。

## 项目结构

```
invoice2Excel/
├── ui/                    # 前端表单（原生 HTML/CSS/JS，编译期嵌入 exe）
│   ├── index.html
│   ├── style.css          # 蓝色主题（对照设计稿）
│   └── app.js             # 预设选项、校验、预览逻辑
├── assets/
│   └── 使用说明.txt        # 源副本，打包时随 exe 一起复制到 dist/
├── scripts/               # 打包脚本：clean-dist / pack-dist / zip-dist
├── src-tauri/
│   ├── src/main.rs        # Tauri 命令：另存对话框、必填/明细过滤、文件名、打开文件夹
│   ├── src/excel.rs       # 按模板复刻的 Excel 生成（rust_xlsxwriter）
│   ├── src/rmb.rs         # 人民币大写转换（含单测）

├── tools/                 # 图标生成脚本
└── package.json           # npm 命令编排（dev / build / zip / test / icon）
```

## 行为约定

- **空行**：摘要、金额、附单据数全部为空才算空行；只填其中一项会在生成时被行完整性校验拦截。
- **合计行**：等于有效明细金额之和；所有金额为空时合计行留白。
- **取消另存对话框**：不生成文件，窗口提示保持空白。
- **姓名/部门**中含 `\/:*?"<>|` 时，文件名里自动替换为下划线。
